# Engenharia-de-Dados-UFS
Trabalho Prático de Engenharia de Dados (UFS) - CRUD Relacional (PostgreSQL), NoSQL (MongoDB) e ETL (Apache Hop).

## Sobre o trabalho

Desenvolvimento de aplicações em bancos de dados relacionais e não relacionais e implementação de rotinas de integração dos dados num banco de dados no esquema estrela.
